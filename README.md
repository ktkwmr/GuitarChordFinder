# Guitar Chord Finder

A web app that finds guitar chord shapes in any tuning. Choose a tuning (DADGAD, Open G, Drop D, … or your own), a root, and a chord type, and it shows natural shapes in the low, middle, and high positions. Tap a shape to hear it, or press frets on the fretboard to name a chord.

ギターの変則チューニングでのコードの押さえ方を探す Web アプリです。チューニング（DADGAD・オープンG・ドロップDなど、または自分で設定）とコードを選ぶと、ロー・ミドル・ハイのポジションごとに自然な押さえ方を表示します。押すと音が鳴り、指板で押さえ方を指定してコード名を調べることもできます。

**▶ https://ktkwmr.com/guitarchordfinder/** (日本語: https://ktkwmr.com/guitarchordfinder/ja/)

## Features / 機能

- **Any tuning**: 10 presets or set each string. Shows how far each string is from standard, and the chord the open strings make
  プリセット 10 種類か、弦ごとに設定。スタンダードからの半音数と、開放弦の響き（コード名）を表示
- **Chord → shapes**: 16 chord types and slash chords, with low / middle / high positions and interval labels
  16 種類のコードと分数コード。ロー・ミドル・ハイのポジションごとに、度数付きで表示
- **Hear it**: note by note, as a chord, or both (Web Audio API)
  1 音ずつ・和音・その両方で再生（Web Audio API）
- **Shape → chord**: press frets to see the chord name and other possible names
  押さえ方からコード名と別の解釈を表示
- **Installable PWA** that also works offline after the first visit
  ホーム画面に追加でき、一度開けばオフラインでも動作
- **English / Japanese UI**, chosen automatically from your browser language. `/guitarchordfinder/ja/` is always Japanese, and `?lang=en` / `?lang=ja` overrides both
  英語・日本語の表示に対応。ブラウザの言語で自動選択。`/guitarchordfinder/ja/` は常に日本語で、`?lang=en` / `?lang=ja` で切り替えも可能

## Privacy / プライバシー

- Everything (the search, the chord names, and the sound) runs only in your browser. Nothing you choose is sent to a server. The app has no accounts, cookies, ads, or third-party libraries.
- For offline use, the app is saved in your browser's storage, together with your settings (tuning, chord, playback mode, and the shape on the fretboard). Clear this site's data to remove them.
- The site is hosted on Cloudflare, which keeps standard access logs (IP address, time, requested page) for operation and security. Page views are counted with Cloudflare Web Analytics, which uses no cookies.

- 検索・コード名の判定・音の再生はすべてブラウザ内で行い、選んだ内容はサーバーに送信されません。アカウント登録・Cookie・広告・外部ライブラリはありません。
- オフラインで使えるよう、アプリ本体と設定（チューニング・コード・再生のしかた・指板の押さえ方）をブラウザ内に保存します。サイトデータを削除すると消えます。
- サイトは Cloudflare で配信しており、運用・セキュリティのために標準的なアクセスログ（IP アドレス、日時、アクセスしたページ）が記録されます。閲覧数は Cookie を使わない Cloudflare Web Analytics で集計しています。

The same notice is shown in the app under ⚙ → **Privacy**. The full privacy policy is at `/guitarchordfinder/privacy/` (Japanese: `/guitarchordfinder/ja/privacy/`), and the operator information is at `/guitarchordfinder/about/`.
アプリ内の ⚙ → **プライバシー** でも同じ内容を表示しています。プライバシーポリシーは `/guitarchordfinder/ja/privacy/`、運営者情報は `/guitarchordfinder/ja/about/` にあります。

## Project structure / 構成

```
public/
  _headers                      # security headers (CSP etc.)
  404.html                      # page for unknown URLs under /guitarchordfinder/ (status 404)
  guitarchordfinder/
    index.html                  # the whole app (HTML / CSS / JS, English and Japanese text)
    ja/index.html               # Japanese page, generated from index.html (do not edit)
    about/  privacy/            # info pages, generated from scripts/pages/ (do not edit)
    ja/about/  ja/privacy/      # Japanese info pages, generated (do not edit)
    sitemap.xml                 # generated by scripts/build-pages.mjs (do not edit)
    sw.js                       # Service Worker (network first, offline fallback)
    manifest.json               # PWA manifest
    icons/                      # icon.svg and PNGs (scripts/render-icons.mjs)
    og-image.png                # image for search results and social media shares
    THIRD_PARTY_LICENSES.md     # third-party notices (shown in About)
scripts/
  build-ja.mjs                  # generates ja/index.html from index.html
  build-pages.mjs               # generates the info pages and sitemap.xml from scripts/pages/
  pages/                        # page content (one file per page, English and Japanese) and layout
  update-third-party-licenses.mjs
  og-image.html                 # source of og-image.png
  render-og-image.mjs           # renders og-image.html to og-image.png (Playwright)
  render-icons.mjs              # renders icons/icon.svg to the PNG icons (Playwright)
wrangler.jsonc                  # Cloudflare Workers (static assets, route ktkwmr.com/guitarchordfinder*)
CLAUDE.md                       # instructions for Claude Code
docs/baseline-status.md         # status of the shared web app baseline items
```

This is the second app on `ktkwmr.com`. Its Worker only serves `/guitarchordfinder/*`; the domain root (`/`, `robots.txt`, the root `sitemap.xml`, and 404 for other paths) belongs to the [Chord Transposer](https://github.com/ktkwmr/ChordTransposer) Worker.
`ktkwmr.com` の 2 つ目のアプリです。この Worker は `/guitarchordfinder/*` だけを配信し、ドメイン直下（`/`、`robots.txt`、ルートの `sitemap.xml`、その他のパスの 404）は Chord Transposer の Worker が持っています。

When you load a script or data from a new external host, add it to the `Content-Security-Policy` in `public/_headers`, or the browser will block it. Also update the privacy text (see below).
新しい外部サイトからスクリプトやデータを読み込むときは、`public/_headers` の `Content-Security-Policy` にそのホストを追加してください（追加しないとブラウザにブロックされます）。プライバシーの説明も同時に直します（下記）。

## Development / 開発

Serve `public/` with a local server and open `/guitarchordfinder/`. Opening `index.html` as a `file://` URL does not work (the Service Worker and the license file need a server).
ローカルのサーバーで `public/` を配信して `/guitarchordfinder/` を開きます。`file://` で直接開くと Service Worker などが動きません。

```sh
npx wrangler dev        # http://localhost:8787/guitarchordfinder/ (also runs the generators)
# or
npx serve public
```

On Windows PowerShell, use `npx.cmd` if `npx` is blocked by the execution policy.
Windows の PowerShell で `npx` が止められるときは `npx.cmd` を使います。

If the app shows an old version, reload the page (or restart the installed app); the Service Worker fetches the latest files first and uses the cache only when offline.
古い画面が出るときは再読み込み（ホーム画面のアプリは再起動）してください。Service Worker はネットワークを優先し、キャッシュはオフライン時だけ使います。

## Deploy / デプロイ

The app is served with Cloudflare Workers static assets. With Workers Builds connected to this repository, a push to `main` deploys automatically, and other branches get preview builds. To deploy by hand:

```sh
npx wrangler deploy
```

## Generated files / 生成ファイル

Edit only `public/guitarchordfinder/index.html` and `scripts/`. These files are generated and must not be edited by hand:

- `public/guitarchordfinder/ja/index.html` – `index.html` with Japanese `<head>` (title, description, canonical, Open Graph, JSON-LD) and Japanese UI text, so search engines can index the Japanese version. The Japanese title and description are in `scripts/build-ja.mjs`; UI text comes from `I18N.ja` in `index.html`.
- `public/guitarchordfinder/{about,privacy}/`, `ja/{about,privacy}/`, and `sitemap.xml` – from `scripts/pages/<slug>.mjs` (English and Japanese written separately) and `scripts/pages/layout.mjs`.

They are regenerated automatically by `npx wrangler deploy` / `npx wrangler dev` (`build.command` in `wrangler.jsonc`) and by the **Build generated pages** GitHub Actions workflow on push to `main`. To run them manually:

```sh
node scripts/build-ja.mjs             # regenerate ja/index.html
node scripts/build-pages.mjs          # regenerate the info pages and sitemap.xml
node scripts/build-ja.mjs --check     # exit 1 if out of date (same for build-pages.mjs)
```

To add an article, create `scripts/pages/<slug>.mjs` and add the slug to `PAGES` in `scripts/build-pages.mjs`; it is added to the footer of every page and to the sitemap.

When a service that receives visitors' information is added or removed (for example ads), update `scripts/pages/privacy.mjs` and its dates, the Privacy text in the app (`privacy.body` in `index.html`), and this README in the same change.

編集するのは `public/guitarchordfinder/index.html` と `scripts/` だけです。`ja/index.html`、情報ページ（運営者情報・プライバシーポリシー）、`sitemap.xml` は生成ファイルなので手で編集しません。デプロイ時（`wrangler deploy` / `wrangler dev`）と `main` への push 時（GitHub Actions）に自動で再生成されます。外部サービスを足す・外すときは、プライバシーポリシー（`scripts/pages/privacy.mjs`）、アプリ内の `privacy.body`、この README を同時に直してください。

## Third-party licenses / サードパーティライセンス

The app uses no third-party libraries. If a CDN library (`cdn.jsdelivr.net/npm/…` or `unpkg.com/…`) is added under `public/`, the **Update third-party licenses** GitHub Actions workflow adds its entry and license text to [`public/guitarchordfinder/THIRD_PARTY_LICENSES.md`](public/guitarchordfinder/THIRD_PARTY_LICENSES.md) on push to `main`. Pin the version in the URL, and add the host to the CSP.

```sh
node scripts/update-third-party-licenses.mjs          # add missing entries
node scripts/update-third-party-licenses.mjs --check  # exit 1 if the file would change
```
